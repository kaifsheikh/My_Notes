1. Skill ek, script ya instructions ka set hota hai jo AI agent ko kisi specific task ko step-by-step perform karne ki kabiliyat deta hai.

2. opencode mein skill wala section file manager mein ja kar manual check kar sakte hain.

# What is Plugin:

1. Ek Plugin aik aisa chhota software add-on ya extension hota hai jo kisi bade software (main application) mein pehle se maujood features ke ilawa naye functions aur tools add karta hai.
   - Local Execution: Plugins aam tor par user ke system ya project ke andar local folders (jaise node_modules) mein install hote hain.

   - Direct Integration: Yeh main application ke code ke sath direct mil kar kaam karte hain aur software ki functionality ko extend karte hain.

   - Aasan Misaal: Jaise Web Browser (Chrome) mein aap extra extensions ya ad-blockers install karte hain jo browser ko mazeed kaam karne ke qabil banate hain.

# What is MCP Server:

1. MCP (Model Context Protocol) ek modern open standard protocol hai jo AI assistants aur agents (jaise Opencode) ko external tools, databases, files, aur remote services ke sath secure tareeqe se connect karne ke liye banaya gaya hai.
   - Yeh AI model ko direct batata hai ke kaun kon se tools available hain aur unhe kaise istemal karna hai, bina mukammal code ko local download kiye.
