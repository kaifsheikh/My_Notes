"Jev" (jise **Jev AI** ke naam se bhi jaana jata hai) market mein **bohat zyada demand** mein hai, lekin yeh koi aam product nahi balki ek **naya aur inqilabi AI model** hai. Aapne jo "Jev" ke baare mein suna hai, woh ek aisa AI hai jo **baat nahi karta, likhta nahi, balki sirf faislay karta hai**. Isi wajah se yeh developers aur investors dono ki nazar mein hai.

### 🤔 Jev Asal Mein Kya Hai?

Jev, **TypeSafe AI** naam ki ek startup ka pehla product hai, jise OpenAI ke ek former researcher, **Diogo Almeida**, ne banaya hai. Is model ko **"System 1 Model"** kaha jata hai, jo insaan ke "fast, intuitive thinking" (tez, fitri soch) se inspired hai.

Iska kaam bilkul mukhtalif hai:
*   **Yeh text generate nahi karta:** Ye ChatGPT ki tarah baatein ya articles nahi likhta.
*   **Yeh sirf faisla karta hai:** Aap ise ek sawaal aur kuch options dete hain, aur yeh turant bata deta hai ke kaunsa option behtar hai, ya kis cheez ka kya score hai.
*   **Yeh structured output deta hai:** Yeh aapko "Choice" (intekhab), "Score" (number), ya "True/False" (sahi/ghalat) ke saath ek confidence level deta hai.

Aasan lafzon mein, agar ChatGPT ek aisi machine hai jo aapke liye essay likh sakti hai, to Jev ek aisi machine hai jo aapke software ke andar baith kar yeh faisla karti hai ke "ab aage kya karna chahiye?" — aur yeh kaam woh **bohat tezi se aur bohat sasti** karti hai.

### 📈 Market Mein Iski Demand Itni Zyada Kyun Hai?

Jev ki demand ki asal wajah iski **speed aur cost** hai, jisne AI industry mein ek naya rujhaan paida kar diya hai.

1.  **Bohat Tez aur Bohat Sasta:** TypeSafe AI ke mutabiq, Jev aam bade AI models (jaise GPT) se **194 guna zyada tez** hai aur **445 guna tak sasta** hai. Iski pricing sirf **$0.042 per million tokens** hai aur output bilkul **free** hai.
2.  **Developers mein Aag Ki Tarah Phela:** Jev sirf 9 din mein viral ho gaya. Platform **Vercel** par, jahan developers models use karte hain, sirf **24 ghanton** mein **13% paid teams** ne ise adopt kar liya, jo GPT-4 se bhi do guna zyada tez adoption thi.
3.  **Investors Ka Paisa Barse Mein:** Jev ki demand dekh kar investors pagal ho gaye hain. Sirf **9 din** ke andar company ki valuation **$200 million** se **$10 billion** tak pahunchne ki khabar hai.
4.  **Naya "Decision Layer" Ka Concept:** Jev ne AI agents ke liye ek naya tareeqa diya hai. Pehle, ek aam AI agent ko har chhota faisla (jaise "kaunsa button dabana hai") karne ke liye bhi ek poora, mehenga LLM call karna parta tha. Ab Jev woh chhote faislay sasti aur tezi se kar sakta hai, jis se agents ko chalana bohat sasta ho jata hai.

### 🛠️ Jev Kaise Use Hota Hai? (Real Examples)

Developers ne Jev ko kai interesting tarikon se use kiya hai:

*   **Browser Automation:** Ek browser agent, Jev ki madad se, Google Flights par **7.1 seconds** mein flights dhoondh kar laaya, aur uski cost sirf **$0.0039** thi.
*   **Gaming AI:** Logon ne Jev ko use kar ke Minecraft khelne wala AI banaya, jo **8 minute 43 seconds** mein ender dragon ko hara diya, aur poori game ki AI cost sirf **$1** se bhi kam thi.
*   **Business Automation:** Customer service mein, Jev aane wali complaint ko parh kar faisla kar sakta hai ke yeh "refund team" ko bhejni hai ya "technical team" ko, bilkul turant.

### 💡 Aapke Liye Iska Kya Matlab Hai?

Aap OpenCode aur TinyFish use kar rahe hain, to Jev aapke liye bohat relevant hai. Jab aap apne AI agent ko koi task dete hain, to us agent ko kai chhote faislay karne parte hain. Jev aise agents ko **bohat sasta aur tez** bana sakta hai.

Kyunki yeh ek naya aur open model hai, aap isay apne local setup mein bhi use kar sakte hain. Developers ne iska open-source version bana kar release kar diya hai jo aam laptops par bhi chal sakta hai. ### 🤔 Jev Ka Kaam Kya Hai? (Ek Line Mein)

Jev **faislay karne** ke liye bana hai — yeh text nahi likhta, balki aapke diye huye options mein se **sab se behtar option chunta hai**, ya **yes/no** ka jawab deta hai, ya kisi cheez ko **score** karta hai.

**Aasan misal:**

Aap ek online store chalate hain. Aap chahte hain ke customer ka message dekh kar pata chale ke woh **kitna naraz** hai.

*   **ChatGPT (LLM):** Aap kehte hain "Is message ko parho aur batao customer naraz hai ya nahi." Woh aapko ek **paragraph** likh kar sunata hai: "Haan, customer naraz lag raha hai kyunki usne teen baar contact kiya hai..." Aapko us paragraph ko parh kar khud faisla karna parta hai.
*   **Jev:** Aap Jev ko message dete hain aur poochte hain "Kya yeh customer naraz hai? (yes/no)". Jev turant aapko ek **number** deta hai, jaise `0.95`. Iska matlab hai 95% chance ke customer naraz hai. Aapka code seedha is number ko check kar sakta hai.

Yeh farq hai — **Jev aapko data deta hai, kahani nahi.**

### 🛠️ Jev Seekhne Ke Liye Kya Aana Chahiye?

Jev ko use karne ke liye **machine learning ya AI ki koi background zaroori nahi hai**. Aapko sirf itna aana chahiye:

| Zaroori Cheez | Kitna Aana Chahiye? |
|---|---|
| **Python (ya JavaScript)** | Basic level — variables, functions, dictionaries, `if/else` statements |
| **JSON format** | Samajh honi chahiye ke JSON kya hota hai aur kaise likha jata hai |
| **API call karna** | Ek simple HTTP request bhejna aur response parhna |
| **Jupyter Notebook** | Basic level (optional, lekin helpful) |

**Zaroori nahi hai:**
- ❌ Machine Learning ka background
- ❌ System One ya type systems ki knowledge
- ❌ LangChain ya kisi specific framework ki knowledge

Yeh baat khud Jev ke documentation mein saaf likhi hai: *"You don't need to know System One, type systems, or LangChain in advance."*

### 📚 Jev Kaise Seekhein? (Step-by-Step)

Jev ko seekhne ka sab se aasan tareeqa yeh hai:

**Step 1: Python ki basic knowledge hasil karein**
Agar aap Python nahi jaante, to pehle basic Python seekh lein. Jev ke saare official examples Python mein hain, aur yeh sab se aasan language hai shuru karne ke liye.

**Step 2: OpenRouter par account banayein aur API key lein**
OpenRouter ek platform hai jahan aap ek hi API key se Jev aur doosre models use kar sakte hain. `openrouter.ai/keys` par ja kar free API key bana sakte hain.

**Step 3: Jev ke teen sawaal (primitives) samjhein**
Jev sirf **teen tarah ke sawaal** pooch sakta hai:

| Sawaal Ka Naam | Kya Karta Hai? | Misal |
|---|---|---|
| **Noul** | Yes/No sawaal | "Kya yeh email urgent hai?" |
| **Choice** | Options mein se ek chunna | "Yeh kis team ko bhejna hai?" |
| **Score** | Kisi cheez ko score dena | "Yeh ticket kitna urgent hai?" |

Yeh teen cheezein samajh aa jayen to aap Jev ka 80% kaam kar sakte hain.

**Step 4: Hands-on course ya tutorial follow karein**
Jev ke liye kuch behtareen free resources available hain:
- **"Learn Jev end to end"** — GitHub par ek free course hai jismein aap 13 real AI tools bana kar seekhte hain. Poora course sirf **$0.20** mein mukammal ho jata hai.
- **Official TypeSafe documentation** — `docs.typesafe.ai` par Jev ke saare concepts aur examples available hain.
- **OpenRouter ka Jev Tutorial** — Bilkul zero se shuru karke pehla Jev call karne tak le jata hai.

**Step 5: Apne project mein Jev ko integrate karein**
Jab aap basics seekh lein, to apne existing code (jaise OpenCode agent) mein Jev ko daal sakte hain. Jev ko Python SDK, TypeScript SDK, ya seedha HTTP API se call kiya ja sakta hai.

### 💡 Ek Ahem Baat

Jev ko seekhna **1-2 din ka kaam hai** — yeh koi mahino ka course nahi hai. Kyunki Jev ka concept bohat simple hai: aap ek sawaal poochte hain, aap options dete hain, aur Jev ek **number** wapas deta hai. Bas.

Aapko sirf itna samajhna hai ke **kab Jev use karna hai** (chhote, fast faislay ke liye) aur **kab LLM use karna hai** (likhne, samjhane, aur plan karne ke liye). Yeh samajh aa jaye to aap Jev ko apne agents mein effectively use kar sakte hain.

# Installation Process:

```py
import os
from dotenv import load_dotenv
from typesafe_sdk import Noul, TypeSafeClient

load_dotenv()

client = TypeSafeClient(
    api_key=os.environ["OPENROUTER_API_KEY"],
    base_url="https://openrouter.ai/api",
)

data = input("📝 Data: ")
sawaal = input("❓ Sawaal: ")

result = client.system_one(
    model="jev-1.13",
    state=data,
    questions={"q": Noul(instructions=sawaal)},
)

prob = result.answers["q"].noul

print(f"\n✅ {prob*100:.0f}% Haan")
print(f"❌ {(1-prob)*100:.0f}% Nahi")
```
