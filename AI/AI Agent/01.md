Bilkul! Main aapko **bilkul shuruaat se** step-by-step batata hoon, taake aap bina kisi confusion ke Opencode ko Groq API ke saath configure kar saken aur VS Code mein use kar saken.

---

## 🧰 **Step 1: Node.js Install Karein (Agar pehle se nahi hai)**

Opencode Node.js par chalta hai, isliye pehle Node.js install karna hoga.

- **Check karein:** Terminal kholen aur type karein:
  ```bash
  node --version
  ```
  Agar version dikh jaye (jaise `v18.x` ya `v20.x`), to Node installed hai. Warna install karein.

- **Install karne ke liye:**
  - [Node.js official website](https://nodejs.org) par jayen.
  - **LTS version** download karein (Recommended for most users).
  - Installer chala kar Next/Next karte hue install kar lein.
  - Install hone ke baad terminal restart karein.

---

## 📦 **Step 2: Opencode AI Install Karein (Global)**

Terminal mein yeh command chalayen:
```bash
npm install -g opencode-ai
```

**Verify:** 
```bash
opencode --version
```
Agar version number dikh jaye, to installation successful hai.

---

## 🔑 **Step 3: Groq API Key Banayein**

1. Browser mein jayen: [https://console.groq.com](https://console.groq.com)
2. Apna account banayein ya login karein (Google/GitHub se bhi ho sakta hai).
3. Left sidebar mein **"API Keys"** par click karein.
4. **"Create API Key"** button dabayen.
5. Key ko copy kar lein (yeh sirf ek baar dikhti hai, isliye safe jagah rakh lein).

**Note:** API key ko kabhi kisi ke saath share na karein aur na hi kisi public file mein daalein.

---

## ⚙️ **Step 4: Opencode Ko Groq Se Configure Karein (Global Setup)**

Hum **environment variables** ka use karenge taake aapko har project mein alag se config na karna pade.

### **A. Windows Users ke liye:**

1. **Environment Variables window kholen:**
   - Start menu mein "Environment Variables" search karein.
   - "Edit the system environment variables" par click karein.
   - "Environment Variables..." button dabayen.

2. **User variables** section mein "New" par click karein.

3. Teeno variables add karein:
   - **Variable name:** `GROQ_API_KEY`  
     **Variable value:** `aapki-groq-api-key` (jo aapne copy ki thi)
   - **Variable name:** `OPENCODE_PROVIDER`  
     **Variable value:** `groq`
   - **Variable name:** `OPENCODE_MODEL`  
     **Variable value:** `llama-3.3-70b-versatile` (ya jo current model ho)

4. OK dabakar sab windows band kar dein.

5. same is cheez ko cmd ki madaad se foran bhe kar sekhte hai.
   - setx OPENROUTER_API_KEY "aapki-api-key"
   - setx OPENCODE_PROVIDER "API_Provider_Name"
   - setx OPENCODE_MODEL "Model_Name"
---

## ✅ **Step 5: Configuration Test Karein**

Terminal mein yeh command chala kar dekhein ki environment variables set hain ya nahi:

- **Windows (Command Prompt):** `echo %GROQ_API_KEY%`  

Agar API key print ho jaye, to sahi hai.

Ab test ke liye `opencode` chala kar dekhein:
```bash
opencode
```
Agar interactive mode khul jaye aur koi error na aaye, to configuration successful hai. Exit karne ke liye `Ctrl+C` dabayen.

---

## 💻 **Step 6: VS Code Mein Use Karein**

1. **VS Code kholen** aur apna project folder open karein (`File > Open Folder...`).

2. **Integrated Terminal kholen:**  
   `Ctrl + ~` (Windows/Linux) ya `Cmd + ~` (Mac).

3. Terminal mein `opencode` type karein aur Enter dabayen.

4. Ab aap usse instructions de sakte hain, jaise:
   ```
   Mere project mein errors scan karo aur fix karo.
   ```

Opencode aapke project ki files padhega, errors dhoondhega, aur fix karega (aapki permission ke saath).

---

## 🔄 **Agar Baad Mein Kuch Change Karna Ho**

- **API key change:** Environment variables mein jakar `GROQ_API_KEY` ki value update karein.
- **Model change:** `OPENCODE_MODEL` ki value badal dein (jaise `mixtral-8x7b-32768`).
- **Windows:** Environment Variables window se edit karein.
- **Mac/Linux:** `~/.bashrc` ya `~/.zshrc` mein edit karke `source` karein.

---

## 📝 **Alternative (Global Config File) – Agar Env Vars Pasand Na Ho**

Aap ek global config file bhi bana sakte hain jo har project mein automatically use hogi.

1. Terminal mein yeh command chala kar directory banayein:
   ```bash
   mkdir -p ~/.config/opencode
   ```

2. File banayein:
   ```bash
   nano ~/.config/opencode/config.json
   ```

3. Usme yeh JSON paste karein:
   ```json
   {
     "provider": "groq",
     "model": "llama-3.3-70b-versatile",
     "apiKey": "aapki-groq-api-key"
   }
   ```

4. Save karein (`Ctrl+O`, `Enter`, `Ctrl+X`).

Ab bina environment variables ke bhi kaam chalega.

---

## 🎯 **Summary**

- Node install karo → Opencode install karo → Groq API key banao → Environment variables set karo → Test karo → VS Code terminal mein use karo.
- Ek baar set karne ke baad dobara config nahi karna padega.
- Agar koi bhi error aaye to mujhe batao, main help karunga.
