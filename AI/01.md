# What is Model?

1. Model aik Pre trained mathematical system hota hai. jo bade datasets par train kiya jata hai. Yeh patterns seekhte hai, predictions karte hai, or user ka question ka according new content generate karte hai.

2. jab user koi question karta hai oisa hum input bolte hai or user ka input different type ka ho sekhta hai like:
    * Text
    * Image
    * Audio / Voice
    * Video
    * Number / Prediction
    * Decision (jaise spam hai ya nahi)
    * Action (robot ka movement)

3. Model aik Brain hai jiske pass world wide Knowledge hoti hai her terha ki. lakin aik model ki knowledge sirf utni hoti hai jitna data usko training ke waqt diya gaya. 

4. Usay latest news, aaj ka weather, aap ke emails, ya real-time cheezein nahi pata hoti — jab tak usko external resources se connect nhe karte.

## Model Parameters?
1. Parameter wo numerical values hote hai. jo model ke andar store hoti hain.
2. aur ye decide karte hain ke model input ko kaise process karega aur output kya dega.
3. or parameters floating-point numbers hotay hain String , Integer yeah Words nahe hote hai
4. Agar hum kahein ke GPT-3 ke **175 Billion parameters** hain, to iska matlab hai uske paas 175 billion chotay chotay "knobs" ya "settings" hain jo usay batate hain ke kis lafz ka kya matlab nikalna hai Jitne zyada parameters, AI utna hi smart hota hai.

## Model ka andar Paramter kaha per hote hai?
Model ke andar hotay hain:
1. Weights
2. Biases

## Weight:
1. Weight aik number hota hai
2. jo ye decide karta hai ke kisi input ki importance kitni hai.

## Bias:
1. Bias aik extra number hota hai

# What is AI Agent?

1. AI Agent ek software system hai jo ek pre-trained AI model ko apna dimaag (brain) banata hai, aur us ke saath:
    * **tools**
    * **memory**
    * **planning**
    * **execution loop**
    * **permissions**

inhe jod kar autonomously goal complete karta hai.

2. agent aik complete package hai jisme yeah sub kch hota hai Agar ek bhi cheez missing ho, to agent adhoora hai.

## Agent ke andar pre-trained model hota hai?

**Haan, bilkul hota hai.**

Har AI agent ke andar ek **pre-trained model** hota hai jo uska brain hota hai. Isko “base model” ya “foundation model” kehte hain.

Jaise:

- **AutoGPT** ke andar GPT-4 ya GPT-3.5 hota hai
- **Devin** ke andar koi LLM hota hai (probably GPT ya Claude)
- **Cursor Agent** ke andar GPT-4 ya Claude hota hai
- **OpenAI Operator** ke andar GPT-4o hota hai

Yani agent banane ke liye sab se pehle ek **pre-trained model** chahiye. Woh model agent ka dimaag banta hai.

## Model ko link karke agent banta hai?

**Model ko link karna yeah pehla step hai, lekin sirf model link karne se agent nahi banta.**

### Step 1: Pre-trained model lo
Jaise GPT-4, Claude, Llama — koi bhi.

### Step 2: Model ko “link” karo
Yani apne code mein model ka API call lagao. Ab aap ka system model se baat kar sakta hai.

### Step 3: `Tools add` karo
Model ko tools do:

- Web browser
- Search engine
- Calculator
- Code interpreter
- File system
- Email API
- Payment API
- Database

### Step 4: `Memory` add karo
- Short-term memory (current task)
- Long-term memory (past interactions)
- Vector database (knowledge store)

### Step 5: `Planning / Execution Loop` banao
Yeh sab se important hissa hai:

**Observe → Think → Act → Check → Repeat**

- Observe: dekho kya ho raha hai
- Think: model se poocho agla step kya hai
- Act: tool use karo
- Check: result sahi hai ya nahi
- Repeat: jab tak goal complete na ho

### Step 6: `Guardrails / Permissions` do
- Kitna paisa kharch kar sakta hai
- Kya delete kar sakta hai
- Kya email bhej sakta hai
- Kis cheez ke liye insaan se permission lega

### Step 7: Ab agent ready hai

## example

- **Engine** = Pre-trained model (GPT-4)
- **Engine ko car mein daalna** = Model ko link karna
- **Steering, brakes, accelerator** = Tools
- **Fuel tank** = Memory
- **Driver ka dimaag** = Planning loop
- **Traffic rules** = Guardrails
- **Poori car** = Agent

# Type of AI Agent:

1. **Conversational Agents**: Sirf baat karte hain, jawab dete hain (ChatGPT, customer support bots).
2. **Task-Oriented Agents**: Khaas kaam karte hain (flight book karna, data scrape karna).
3. **Autonomous Agents**: Lambey kaam khud plan karke karte hain (AutoGPT, Devin).
4. **Multi-Agent Systems**: Kayi agents milkar kaam karte hain (research, writing, review).
5. **Embodied Agents**: Physical robots ya game AI.

# Agentic AI?

* **Simple Lafzon Mein:** Agentic AI ek aisi advanced AI hai jo sirf aapke sawalon ke jawab nahi deti, balkay khud se faislay kar ke poora kaam **complete (execute)** karti hai.

* **Misaal:** Normal AI (jaise ChatGPT) ek **Consultant** ki tarah hai—aap sawal poochte hain, woh mashwara ya text deti hai. Jabke Agentic AI ek **Autonomous Employee** ki tarah hai—aap sirf maqsad (goal) batate hain, aur woh baqi poora kaam khud plan aur execute karti hai.

# Normal AI (Generative AI) vs Agentic AI

| Feature | Normal AI (Generative AI) | Agentic AI |
| --- | --- | --- |
| **Kaam Ka Tarika** | Text ya answers generate karti hai. | Actions leti hai aur tasks poore karti hai. |
| **Insaan Ka Role** | Har step par insaan ko khud instruction deni parti hai. | Insaan sirf ek baar **Goal** deta hai, baqi AI khud karti hai. |
| **Flight Booking Example** | Aapko Lahore ki flights ki list bana kar de gi, ticket aapko khud book karni pare gi. | Internet par search kare gi, prices compare kare gi, payment kare gi, aur ticket email par bhej de gi. |
| **Output Type** | Answers (Jawab) | Outcomes (Nateeje) |

# Agentic AI Kaise Kaam Karti Hai?

Agentic AI kisi bhi kaam ko poora karne ka liya 4 steps follow karta hai:

* **Step 1: Goal Understanding (Maqsad Samajhna)**
* AI aapke diye gaye task ka maqsad aur uski limits (rules) samajhti hai.
* *Misaal:* Agar aap kahein "Laptop dhoond kar do", toh woh pehle samajhti hai ke budget kya hai aur kaun se features zaroori hain.


* **Step 2: Planning & Task Breakdown (Kaam Ko Chote Steps Mein Torhna)**
* Bade kaam ko chote, sequential steps mein taqseem karti hai.
* *Misaal:* Step 1: Specs comparison -> Step 2: Reviews read karna -> Step 3: Best price dhoondna -> Step 4: Purchase link generate karna.


* **Step 3: Execution & Tool Use (Tools Ka Istemal)**
* Zaroorat ke mutabiq alag-alag digital tools (Web Search, APIs, Python Code, Databases, Excel) ko khud chalati hai.
* *Misaal:* Python code chala kar internet se real-time prices scrape karna ya database mein entry karna.


* **Step 4: Self-Reflection & Re-try (Khud Ko Check Karna)**
* Agar koi step fail ho jaye (e.g., koi website na khule ya code mein error aaye), toh AI rukti nahi hai. Woh error ko samajh kar apna rasta badalti hai aur dobara koshish karti hai.

---

**4. Real-Life Examples (Har Field Mein Istemal)**

* **Software Engineering & Coding:**
* *Kaam:* Developer sirf kehta hai "Login page par Google Sign-In button lagao."
* *Agentic Role:* AI khud code likhti hai, files update karti hai, bugs test karti hai, aur code server par **deploy** kar deti hai.

---

**5. Agentic AI Ka Asli Purpose (Maqsad)**

Agentic AI ka sab se bara maqsad insaanon ko **repetitive, multi-step, aur time-consuming digital tasks** se azaad karna hai. Normal AI aapko *rasta batati hai*, jabke Agentic AI us *raste par khud chal kar manzil tak puhanchati hai*.
