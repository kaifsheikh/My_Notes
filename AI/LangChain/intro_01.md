# What is LangChain?

1. LangChain ek open-source framework hai jo LLM jaise AI models ko tools, data, aur external systems se connect karne ki permission deta hai taake wo real-world jaise kam ko bhe easily kar sekhe.
2. AI Models sirf Data ki base per Train hote lakin Current situation nhe bta sekhte hai tu is problem ko dour karta hai lainchain.
3. LangChain ek **bridge** hai jo **AI aur aapke computer programs, websites, databases, Excel files, APIs** ke beech kaam karwata hai
4. automatically chalana: Aap chahte hain "pehle search karo, phir jawab banao, phir save karo". LangChain Chain banata hai jo yeh saare steps khud-ba-khud chala deti hai—aapko manually har step nahi likhna padta.
5. Model ko tools dena: Agar AI ko calculation karni ho, web search karna ho, ya file read karni ho, LangChain Tools ke zariye yeh mumkin banata hai. Model khud decide karta hai ke kab kaunsa tool call karna hai.
