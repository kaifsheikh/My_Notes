### Step 1: Buniyadi Maaloomat (Basic Concepts) Seekhein

Sab se pehle yeh samajhna zaroori hai ke software banta kaise hai aur market mein iska lifecycle kya hota hai.

* **SDLC (Software Development Life Cycle):** Yeh seekhein ke aik software shuru se lekar akhir tak (banne se lekar launch hone tak) kin stages se guzarta hai.
* **STLC (Software Testing Life Cycle):** Yeh sab se ahem hai! Isme aap seekhenge ke testing ka poora process kaise chalta hai (Planning se lekar Bug reporting tak).
* **Kahan se seekhein?** YouTube par search karein: *"SDLC and STLC in Urdu/Hindi"*. Bohot achi aur aasan videos mil jayengi.

### Step 2: Manual Testing Par Pakar Banayein

Shuru mein aapko **bilkul coding nahi karni**. Aapne sirf Manual Testing seekhni hai. Isme yeh cheezein cover karein:

* **Test Cases Likhna:** Yeh sikhain ke kisi app ya website ke liye test cases kaise likhe jate hain (misal ke tor par: login page ke liye kya test cases honge).
* **Bugs Report Karna:** Yeh sikhain ke agar koi ghalti nazar aaye toh usko professional tareeqay se kaise likhte hain aur screen recording ya screenshot kaise attach karte hain.
* **Testing ki Qismein:** Functional Testing, UI/UX Testing, aur Usability Testing kya hoti hai, yeh parhein.
* **Kahan se seekhein?** YouTube par search karein: *"Manual Testing full course in Urdu/Hindi"* (jaise Naveen AutomationLabs ya kisi aur achay tutor ke free courses).

### Step 3: Industry ke Famous Tools Seekhein

Jab aapko manual testing ki samajh aa jaye, toh kuch buniyadi tools chalana seekhein jo har SQA job mein use hote hain:

* **Jira:** Yeh aik tool hai jahan bugs aur tasks track kiye jate hain. Isko chalana seekhein (YouTube par tutorials mil jayenge).
* **Postman:** Yeh API Testing ke liye use hota hai (Iska basic use sikhna bohot zaroori hai).

### Step 4: Practical Practice Karein (Sab se Ahem)

Sirf video dekhne se kuch nahi hoga, khud hath chalana parega:

* Apne phone ki kisi bhi aam app (jaise WhatsApp, Instagram, ya Daraz) ko kholen aur sochein ke isme kya kya kharabi ho sakti hai.
* Ek choti si notebook ya file banayein aur usmein Daraz app ke login page ya cart page ke liye **Test Cases** khud likh kar practice karein.

### Step 5: Resume Banayein aur Apply Karein

Jab aap Manual Testing aur Jira/Postman sikh lein, toh apna aik simple sa **SQA Resume** banayein jisme likhein ke aapko Manual Testing, Test Case writing, aur Bug tracking aati hai. Phir LinkedIn ya local software houses mein Intern ya Junior SQA ki positions ke liye apply karna shuru kar dein.
