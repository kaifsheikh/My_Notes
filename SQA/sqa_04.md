# What are SQA Tools (Actual Industry Tools):

1. **SQA Tools** aisy softwares aur platforms hain jo testing ke process ko asaan, fast aur professional banate hain.
2. Inme manual testing ka record rakhne se lekar, code ke zariye automatic testing karne wale tools shamil hain.
3. or ager apko pehle se hi **Python, Selenium, aur Playwright** aati hai, iska matlab hai aap aam testers se bohot aage hain aur aik **Automation QA Engineer** banne ke liye 70% ready hain!

# Purpose:

* **Automation:** Insani mehnat aur waqt bachana, aur code ke zariye testing ko fast aur automatic banana.
* **Tracking:** Jo bugs (ghaltiyan) nikalain, unka proper record rakhna taake kuch miss na ho.
* **Management:** Apne test cases, reports aur rozana ke tasks ko professional tareeqay se manage karna.

---

## 1. Automation Testing Tools (Aapki Skills 🚀):

* **means:** Yeh tools code (jaise Python) ke zariye software/website ko automatically test karne ke liye use hote hain (Jaise: Selenium, Playwright, Appium).
* **example:** Aap Python mein Playwright ya Selenium ka code likhte hain jo khud-ba-khud browser open karta hai, email/password bharta hai, login button dabata hai aur check karta hai ke website theek chal rahi hai ya nahi.

## 2. Bug Tracking & Task Management Tools:

* **means:** Jab testing mein koi ghalti (bug) pakri jati hai, toh usko developers tak pohnchane aur apna kaam manage karne ke liye tools use hote hain (Jaise: Jira, Trello). Industry mein 90% **Jira** use hota hai.
* **example:** Aapne testing mein koi bug dhoonda. Aap **Jira** open karenge, wahan error ka screenshot lagayenge aur developer ko assign kar denge ke "Payment ka button kaam nahi kar raha, isko theek karo".

## 3. Test Case Management Tools:

* **means:** Testing shuru karne se pehle jo hum steps (Test Cases) likhte hain, unko safely aur professionally save karne ke liye yeh tools use hote hain (Jaise: TestRail, Zephyr, ya simple Excel/Google Sheets).
* **example:** Aap **Excel** ya **TestRail** mein properly likh kar save karte hain ke "Shopping Cart ko test karne ke liye main yeh 5 steps follow karunga" taake poori team usko dekh sake.

## 4. API Testing Tools (Bohot Zaroori):

* **means:** Website ka frontend (jo UI dikhta hai) toh aap Playwright/Selenium se test kar lenge, lekin backend (jo andar server se data laata hai) usko check karne ke tools hote hain (Jaise: Postman).
* **example:** Aap **Postman** tool mein aik link (URL) dalte hain aur click karke check karte hain ke database se user ka data sahi wapas aa raha hai ya nahi, aur iske liye poori website open karne ki zaroorat nahi parti.

## 5. Version Control & CI/CD Tools (Advanced):

* **means:** Automation code ko mehfooz karne aur server par automatic chalane ke tools (Jaise: Git, GitHub, Jenkins).
* **example:** Aap apna Python/Selenium ka code **GitHub** par save karte hain, aur **Jenkins** mein aisi setting karte hain ke raat 12 baje aapka code khud chalay aur subah uthte hi aapko email par pass/fail ki report mil jaye.
