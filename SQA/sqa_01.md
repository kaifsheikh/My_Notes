# SQA?

1. **SQA** means **Software Quality Assurance**

2. SQA aik aisi field hai jisme software ki quality ko check kiya jata hai taake market mein launch honay se pehle uski galtiyon ko theek kiya ja sake.

# Purpose:

* **software ki testing karna:** nahi hota, balkay poore development process ko behtar banana hota hai taake ghaltiyan start mein hi roki ja saken.
* **Bugs Khatam Karna:** Software mein mojood kharabiwon aur errors ko dhoond kar theek karna.
* **User Experience Behtar Banana:** Software itna aasan aur smooth ho ke user ko istamal karte waqt koi mushkil na ho.
* **Waqt aur Paisa Bachana:** Agar software market mein jane ke baad kharab nikle toh usko theek karna mushkil aur mehanga parta hai. SQA shuru mein hi ghaltiyan pakar leta hai.

# SQA Kahan Use Hota Hai:

SQA har us jagah use hota hai jahan software, mobile apps, ya websites banti hain:

* **Tech Companies & Software Houses:** Jahan naye software ya apps taiyar hote hain.
* **E-commerce Websites:** Jaise online shopping ki apps (Amazon, Daraz vaghairah) jahan payment aur browsing system ka theek chalna zaroori hai.
* **Banking & Finance Apps:** Jahan security sab se ahem hoti hai.
* **Gaming Industry:** Games ko bug-free banane ke liye.

# Type of SQA:

* SQA ki mainly 2 type of hoti hai jisme or mazeed choti types hoti hain. 
    - **Manual Testing**
    - **Automation Testing**

## 1. Manual Testing:

Ismein tester khud aik aam user ki tarah software ya app ko chala kar dekhta hai. Woh buttons click karta hai, forms bharta hai, aur check karta hai ke sab kuch theek chal raha hai ya nahi.

* **Isme kya hota hai?** Iske liye **koi coding ki zaroorat nahi parti**.
* **Kab use hoti hai?** Jab koi nayi app ya screen pehli baar banti hai aur usko insani aankh se check karna zaroori hota hai.

## 2. Automation Testing (Tools aur Code se Testing karna)

Ismein tester khud bar-bar testing nahi karta, balkay computer ko kuch code ya scripts likh kar de deta hai jo automatic tareeqay se software ko check kar leti hain.

* **Isme kya hota hai?** Iske liye thori bohat **coding** (jaise Python ya Java) aani chahiye.
* **Kab use hoti hai?** Jab aik hi cheez ko baar-bar test karna ho ya bohot bara software ho jisme manual check karna mushkil ho.

# Waht is System Softwares:

1. System Software aik aisa software hota hai jo computer ka main software hota hai.

2. Iska kaam aapko ya kisi aur app ko seedha fida dena nahi hota, balkay yeh computer ke andar baith kar poore system aur doosray software ko chalta aur control karta hai.

## Example:

1. **Operating System (OS)**
2. **Android**
3. **iOS**
4. **Windows**
5. **Mac**

- Yeh sab System Software ki sab se bari examples hain.

# Programmer Software (Programming Tools)

Yeh woh software hote hain jo **programmers aur developers** use karke doosre software, apps, ya games banate hain.

* **Aasan misaal:** Agar aapne ghar banana ho toh aapko haththoray, pechkas, aur doosray tools ki zaroorat parti hai. Bilkul usi tarah, code likhne aur software banane ke liye developers ko **Programmer Software** (jaise VS Code ya compilers) ki zaroorat parti hai.
* **Kaam:** Ismein code likha jata hai, uski ghaltiyan theek ki jati hain, aur usko run karke check kiya jata hai.

# Application Software (Aam Apps)

Yeh woh software hote hain jo **aam users** apni kisi khaas zaroorat ya kaam ke liye mobile ya computer par install karke use karte hain.

* **Aasan misaal:** WhatsApp, TikTok, YouTube, Microsoft Word, ya Google Chrome—yeh sab application software hain.
* **Kaam:** Inka maqsad computer ko chalana nahi hota, balkay aapka koi specific kaam aasan karna hota hai (jaise chat karna, video dekhna, ya document banana).
