# What inside the Cpanel:

Aapke bheje gaye cPanel (InfinityFree hosting) ke **Statistics** aur **Account Details** ke tamam options aur unke maqsad ki tafseel Roman Urdu mein yeh hai:

---

### **Statistics (Shumar-o-Shumar / Stats)**

- **Plan: infinityfree**

- Matlab/Khaas: Yeh batata hai ke aapka hosting account kis package ya tier par chal raha hai.

- **Kaam/Purpose:** Isse pata chalta hai ke aap free plan use kar rahe hain ya paid aur aapko kya limitations mil rahi hain.

- **FTP accounts: 1 / 1**

- Matlab/Khaas: File Transfer Protocol accounts ki taadad.

- **Kaam/Purpose:** Iska matlab hai ke aapke paas 1 FTP account ki limit thi aur aapne 1 use kiya hua hai. Iske zariye aap apni files server par upload ya manage karte hain.

- **Sub-Domains: 1 / Unlimited**

- Matlab/Khaas: Main domain ke andar mazeed chote domains banane ki salahiyat.

- **Kaam/Purpose:** Aap apni main website ke alawa mazeed sub-domains (jaise `blog.ozsyjny6.infinityfree.com`) bana sakte hain, jiski limit yahan infinity/unlimited show ho rahi hai.

- **Add-on Domains: 0 / Unlimited**

- Matlab/Khaas: Bilkul naye aur alag domains ko host karne ki ijazat.

- **Kaam/Purpose:** Iske zariye aap apne ek hi hosting account par mazeed naye domains add kar ke doosri website bhi chala sakte hain.

- **Parked Domains: 0 / Unlimited**

- Matlab/Khaas: Domain aliases ya parked domains.

- **Kaam/Purpose:** Jab aap ek hi website par doosre domain se bhi users ko redirect karna chahte hain.

- **MySQL Databases: 1 / Unlimited**

- Matlab/Khaas: Database ki taadad jo website ka data (jaise users, posts, settings) store karta hai.

- **Kaam/Purpose:** Aapke paas unlimited databases ki limit hai jisme se aapne 1 database banaya hua hai (jaise PHP/MySQL project ke liye zaroori hota hai).

- **Disk Quota: 5 GB**

- Matlab/Khaas: Aapki hosting ka total storage size.

- **Kaam/Purpose:** Server par aapko total 5 GB ki space mili hui hai jahan aap apni website ki files, images aur database save kar sakte hain.

- **Disk Space Used: 14 MB**

- Matlab/Khaas: Kitni storage abhi tak use ho chuki hai.

- **Kaam/Purpose:** Yeh batata hai ke aapne 5 GB me se sirf 14 MB jagah gheri hai.

- **Disk Free: 4986 MB**

- Matlab/Khaas: Kitni storage abhi khali bachi hai.

- **Kaam/Purpose:** Yeh batata hai ke mazeed kitni files upload ki ja sakti hain (4986 MB baaki hain).

- **Inodes Used: 0 % (80 of 80000)**

- Matlab/Khaas: Total files aur folders ki ginti (Inodes).

- **Kaam/Purpose:** Hosting server par sirf size hi nahi balki files ki taadad ki bhi limit hoti hai. Aapke paas 80,000 ki limit hai jisme se sirf 80 files/folders bani hain.

- **Bandwidth: Unlimited**

- Matlab/Khaas: Data transfer ki limit.

- **Kaam/Purpose:** Jab users aapki website par aate hain aur pages load hote hain, toh data transfer hota hai. Yeh unlimited hai.

- **Bandwidth used: 1507 MB**

- Matlab/Khaas: Kitna data ab tak transfer ho chuka hai.

- **Kaam/Purpose:** Aapki website se users ne ab tak 1507 MB (approx 1.5 GB) data download/view kiya hai.

- **Bandwidth remaining: Unlimited**

- Matlab/Khaas: Kitni bandwidth baaki hai.

- **Kaam/Purpose:** Kyunki limit unlimited hai, isliye yeh unlimited show ho raha hai.

- **Daily Hits Used: 2 % (974 of 50000)**

- Matlab/Khaas: Rozana ki requests ya visitor visits ki limit.

- **Kaam/Purpose:** Server par ek din mein maximum 50,000 hits (visits/requests) ki ijazat hai, jisme se aaj 974 hits use hue hain (2%).
