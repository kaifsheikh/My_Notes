GitHub par **`poc`** topic ka matlab **"Proof of Concept"** hai.

Iska asaan lafzoun mein maqsad ye hota hai ke yeh dikhaya jaye ke koi idea, theory, ya software vulnerability (kisi software ki kamzori ya bug) asal mein kaam kaise karti hai.

Mazeed tafseel neechay hai:

1. **Proof of Concept (PoC) kya hai?**
Jab koi naya security bug ya software mein kharabi (vulnerability) samne aati hai, toh developers ya security researchers ek chota sa code ya script banate hain jo ye sabit karta hai ke haan, ye kharabi waqai mojood hai aur iska fayda uthaya ja sakta hai. Is chote se code ko PoC kehte hain.
2. **GitHub par iska kya use hai?**
* **Security Testing:** Ethical hackers aur security experts in tools aur scripts ko use karke check karte hain ke unke systems ya servers mehfooz (secure) hain ya nahi.
* **Learning:** Developers ye samajhne ke liye in projects ko dekhte hain ke software mein kis tarah ki ghaltiyan ho sakti hain aur unhe kaise theek kiya jaye.
* **Bug Bounty:** Jo log security bugs dhoondtay hain, wo apni research share karne ke liye yahan PoC upload karte hain.
