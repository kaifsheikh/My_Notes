# What is Framework:
1. Framework or Libaray dono he programming ki duniya mein ready-made code hota hai jo kisi specific kaam ko asaan banata hai.

2. lakin dono mein difference hai or wo yeah hai ke Framework mein humein code khud likhna hota hai or Library mein humein code sirf use karna hota hai. 

# Difference Between Library or Framework:

## Framework:
1. Framework ek tarah ka ready-made ghar ka structure hai. Jaise kisi ghar ka blueprint jo pehle se tayyar ho.

2. hum framework ke rules follow karte hain or framework he decide karta hai ke cheezein kaise honi chahiyein hum bus specific jagahon par apna code likhte hain or framework baaki ka kaam khud kar leta hai.

3. Ismein rules aur structure pehle se define hote hain.
4. Aapko uss structure ke andar reh kar kaam karna hota hai.
5. Framework aapko control deta hai, lekin ek fixed pattern mein.
6. Example: Laravel, Django, React, Angular

## Example:
Sochiye aap ek ghar bana rahe hain humne kisi builder se ghar ka structure banwa liya means **Blueprint**.

Ab aapko sirf andar ka decoration karna hai (walls ka colour, furniture, etc.). Builder ne already decide kar diya hai ke kitchen kahan hoga, bathroom kahan hoga, windows kahan hon gi.

---

# What is Libaray:

1. Library ek tarah ka toolbox hai. Jaise aapke ghar mein toolbox hota hai jismein hammer, screwdriver, pliers waghera hote hain.
2. Library mein hum decide karte hain ke kab aur kaunsa tool hume use karna hai.
3. Ismein sirf tools hote hain, koi fixed structure nahi hota.
4. Aap jab chahein, jaisa chahein, tool use kar sakte hain.
5. Library mein control aapke paas hota hai.
6. Example: jQuery, Requests (Python), Axios (JavaScript)

## Example:
Sochiye aap ek ghar bana rahe hain:

Library hai jaise aapka personal toolbox. Jab aapko deewar mein keel thokni hai, aap hammer nikal kar use karte ho. Phir wapas rakh dete ho. Aap decide kar rahe ho ke kab hammer use karna hai or kab nahi.
