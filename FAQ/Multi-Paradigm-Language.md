### **Multi-Paradigm Language ka Maqsad (Purpose kya hai?)**

Aik aisi programming language jo **"Multi-Paradigm"** ho, uska asal maqsad developer ko **azadi (flexibility)** dena hota hai. Har project ya masla (problem) aik jaisa nahi hota—kabhi wahan "Object-Oriented" style behtar kaam karta hai, aur kabhi "Functional" ya "Procedural" style. Multi-paradigm language ka matlab hai ke aapko alag-alag languages sikhne ki zaroorat nahi, aap aik hi language mein apni marzi ka coding style chun sakte hain.

---

### **4 Main Points (Detail, Purpose & Examples ke sath)**

#### **1. Object Oriented Programming (OOP)**

- **Matlab:** Isme code ko "Classes" aur "Objects" ki shakal mein likha jata hai, bilkul real-world ki cheezon ki tarah.
- **Maqsad:** Bade aur complex projects ko organize rakhna aur code ko bar bar use (re-use) karna.

#### **2. Functional Programming**

- **Matlab:** Is style ka sara focus "Functions" aur mathematical calculations par hota hai. Isme data ko change (modify) karne ke bajaye naya data return kiya jata hai.
- **Maqsad:** Code mein errors (bugs) ko kam se kam karna aur yeh ensure karna ke function hamesha same input par same output de.
- **Example:** JavaScript ya PHP mein `array_map()` ya `filter()` ka use karna, jahan aap aik list dete hain aur woh bina purani list ko tabaah kiye aik saaf naya output de deta hai.

#### **3. Structured Programming**

- **Matlab:** Isme code ka flow loops (`for`, `while`) aur conditions (`if-else`) ke zariye control hota hai taake code upar se neeche aik saaf tarteeb mein chalay.
- **Maqsad:** Code ko "Spaghetti code" (yaani uljhay huway code) banne se bachana aur logic ko asani se samajhna.
- **Example:** Aik `if-else` block likhna:

```text
agar (user_login == true) {
    dashboard dikhao;
} warna {
    login page dikhao;
}

```

#### **4. Procedural Oriented**

- **Matlab:** Isme code ko step-by-step procedures (ya routines/functions) mein divide kiya jata hai jo aik ke baad aik execute hote hain.
- **Maqsad:** Chote aur seedhe tasks ko asani se likhna jahan step-by-step logic ki zaroorat ho.
- **Example:** Aik program jo pehle database se connection banaye, phir data uthaye, aur aakhir mein screen par print karde—yeh aik procedural flow hai.

---

### **Mukhtasir Khulasa:**

Agar koi language (jaise **PHP**, **Python**, ya **JavaScript**) Multi-Paradigm hai, toh iska matlab yeh hai ke woh aapko yeh sabhi 4 tareeqe use karne ki ijazat deti hai. Aap apni zaroorat ke mutabiq jo chahein woh style apnaya sakte hain!
