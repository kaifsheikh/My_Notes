# Controller:
1. Controller `Model` aur `View` in dono ka Beech mein aza Bridge (`Middleman`) ki terha kam karta hai means.
2. yeah `Model` or `View` dono se Communicate karta hai.  
3. User ki `Request` ko handle karta hai means User ki Request ko Receive karta hai Model se Data fetch karta hai or View ko dy dyta hai.
4. Controller ki Location `app/Http/Controllers/` isme humeri Controllers ki `files` hoti hai.
5. Controller ka Naam humesha `Capital Letters` se start hota hai.
