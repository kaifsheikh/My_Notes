# **Laravel Full MVC – Complete Example**

## **Step 1 – Database create karo**

1. XAMPP start karo aur phpMyAdmin open karo.
2. `laravel_mvc` naam ka database create karo.

Ab Laravel project ki `.env` file open karo aur database settings update karo:

## **`.env` file open karne hai**

```php
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_mvc
DB_USERNAME=root
DB_PASSWORD=
```

## **Step 2 – Model aur Migration banao**

Terminal mein ye command run karo:

```bash
php artisan make:model Student -m
```

Is command se 2 files banengi:

- `app/Models/Student.php` — Model
- `database/migrations/xxxx_create_students_table.php` — Migration

Ab migration file open karo aur `up()` function ke andar ye code rakho:

## **`database/migrations/xxxx_create_students_table.php` yeah file open karne hai**

```php
public function up(): void
{
    Schema::create('students', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->string('course');
        $table->integer('fee');
        $table->timestamps();
    });
}
```

Ab terminal mein run karo:

```
php artisan migrate
```

Isse database mein `students` table create ho jayegi.

## **Step 4 – Controller banao**

Terminal mein command run karo:

```
php artisan make:controller StudentController
```

**File:** `app/Http/Controllers/StudentController.php`

Ye code likho:

```php
<?php

namespace App\Http\Controllers;

use App\Models\Student;
use Illuminate\Http\Request;

class StudentController extends Controller
{
    public function index()
    {
        $students = Student::all();

        return view('students', compact('students'));
    }
}

```

**Simple Explanation:**

- `Student::all()` database se tamam students ka data lekar aayega.
- `$students` variable mein data store hoga.
- `compact('students')` data View ko bhej dega.
- `view('students')` students wali Blade file open karega.

## **6. Step 5 – Route banao**

**File:** `routes/web.php`

```php

<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\StudentController;

Route::get('/students', [StudentController::class, 'index']);
```

## **Step 6 – View banao**

`resources/views` folder mein `students.blade.php` naam ki file create karo.

**File:** `resources/views/students.blade.php`

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Students List</title>
  </head>
  <body>
    <h1>All Students</h1>

    <table border="1" cellpadding="10">
      <tr>
        <th>ID</th>
        <th>Name</th>
        <th>Course</th>
        <th>Fee</th>
      </tr>

      @foreach($students as $student)
      <tr>
        <td>{{ $student->id }}</td>
        <td>{{ $student->name }}</td>
        <td>{{ $student->course }}</td>
        <td>{{ $student->fee }}</td>
      </tr>
      @endforeach
    </table>
  </body>
</html>
```

## **Step 7 – Project Run karo**

Terminal mein command run karo:

```
php artisan serve
```
