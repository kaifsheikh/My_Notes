# **Laravel Installation – Complete Guide**

- PHP se hum websites aur web applications banate hain.
- Laravel PHP ka framework hai jo website banana easy aur fast kar deta hai.
- Ismein routing, database connection, login system, security aur bohot se features pehle se available hote hain.

# **Laravel install main components**

Laravel install karne se pehle kch cheezay phela se installed hone chaiya.

1. **PHP**
2. **Composer**
3. **VS Code**
4. **MySQL**

---

```bash
composer create-project laravel/laravel my-first-app
```

**Ye command kya karegi?**

1. Composer Laravel download karega.
2. Laravel ki required files download hongi.
3. Required PHP packages install honge.
4. `my-first-app` naam ka folder create ho jayega.
5. Laravel ka complete project ready ho jayega.

## **Step 5: Laravel project VS Code mein open karein**

```
C:\laravel-projects\my-first-app
```

## **Step 6: Laravel project run karein**

1. Ab VS Code mein Terminal open karein.

```
php artisan serve
```

2. Agar sab kuch successfully install hua hai toh aapko kuch is tarah ka message milega:

```
INFO  Server running on [http://127.0.0.1:8000]
```

# **Laravel project ka folder structure**

| Folder / File | Iska kaam                              |
| ------------- | -------------------------------------- |
| `app`         | Application ka main PHP code           |
| `routes`      | Website ke URLs define karte hain      |
| `resources`   | HTML, Blade, CSS aur frontend files    |
| `database`    | Database migrations aur seeders        |
| `public`      | Publicly accessible files              |
| `config`      | Application ki settings                |
| `.env`        | Database aur environment configuration |
| `artisan`     | Laravel ki command-line utility        |

# **How to show `Hello World` for the first time:**

## **1. `routes/web.php` - file open karein**

Is file mein aapko kuch is tarah ka code milega:

```php
Route::get('/', function () {
    return view('welcome');
});
```

Is code ko remove karke ye code likh dein:

```php
Route::get('/', function () {
    return 'Hello World';
});
```

**Ye code kya kar raha hai?**

- `Route::get()` browser se GET request receive karta hai.
- `'/'` ka matlab website ka home page hai.
- `function()` ke andar hum batate hain ke page open hone par kya karna hai.
- `return 'Hello World'` browser mein Hello World show karega.

---

## **2. `routes/web.php` - file open karein**

ager custom Route create karna ho tu oisa ka liya yeah karna hoga.

```php

<?php

use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return 'Home Page';
});

// About
Route::get('/about', function () {
    return 'This is About Page';
});

// Contact
Route::get('/contact', function () {
    return 'This is Contact Page';
});

// Services
Route::get('/services', function () {
    return 'This is Services Page';
});
```

---

## **3. `routes/web.php` - file open karein**

how to create Custom Route + Custom Function.

```php

<?php

use Illuminate\Support\Facades\Route;

// Custom Function
function myFunction() {
    return "Hello World From My Function";
}

// Custom Route
Route::get('/hello', function () {
    return myFunction();
});
```

How to pass Dynamic Value to URL

```php

<?php

use Illuminate\Support\Facades\Route;

function student($name) {
    return "Welcome " . $name;
}

Route::get('/student/{name}', function ($name) {
    return student($name);
});
```
