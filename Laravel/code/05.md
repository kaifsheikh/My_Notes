# **4. Model aur Migration create karo**

Terminal mein command run karo:

```
php artisan make:model Product -m
```

Is command se 2 files create hongi:

1. `app/Models/Product.php`
2. `database/migrations/xxxx_create_products_table.php`

**Migration file open karo:**

`database/migrations/xxxx_create_products_table.php`

Code:

```php
public function up(): void
{
    Schema::create('products', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->decimal('price', 10, 2);
        $table->text('description')->nullable();
        $table->timestamps();
    });
}
```

Ab migration run karo:

```bash
php artisan migrate
```

Database table created

# **6. Controller create karo**

Terminal mein command run karo:

```php
php artisan make:controller ProductController --resource
```

File create hogi:

`app/Http/Controllers/ProductController.php`

Ab is file mein complete CRUD code likho:

```php
<?php

namespace App\Http\Controllers;

use App\Models\Product;
use Illuminate\Http\Request;

class ProductController extends Controller
{
    // READ
    public function index()
    {
        $products = Product::all();

        return view('products.index', compact('products'));
    }

    // CREATE
    public function create()
    {
        return view('products.create');
    }

    // STORE
    public function store(Request $request)
    {
        $request->validate([
            'name' => 'required',
            'price' => 'required|numeric',
            'description' => 'nullable'
        ]);

        Product::create($request->all());

        return redirect()->route('products.index')
            ->with('success', 'Product Added Successfully!');
    }

    // EDIT
    public function edit(Product $product)
    {
        return view('products.edit', compact('product'));
    }

    // UPDATE
    public function update(Request $request, Product $product)
    {
        $request->validate([
            'name' => 'required',
            'price' => 'required|numeric',
            'description' => 'nullable'
        ]);

        $product->update($request->all());

        return redirect()->route('products.index')
            ->with('success', 'Product Updated Successfully!');
    }

    // DELETE
    public function destroy(Product $product)
    {
        $product->delete();

        return redirect()->route('products.index')
            ->with('success', 'Product Deleted Successfully!');
    }
}

```

# **7. Routes create karo**

Ye code add karo:

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\ProductController;
