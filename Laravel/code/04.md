# **Laravel Full MVC – Form Data Insert into MySQL**

## **Step 1 – Database create karo**

Ab `laravel_mvc` naam ka database create karo.

## **File:** `.env`

Ab Laravel project ki `.env` file open karo.

Database settings update karo:

```php
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_mvc
DB_USERNAME=root
DB_PASSWORD=
```

## **Step 2 – Model aur Migration banao**

Terminal open karo aur Laravel project ke folder mein ye command run karo:

```
php artisan make:model Student -m
```

Is command se 2 files create hongi:

1. `app/Models/Student.php` — Model
2. `database/migrations/xxxx_create_students_table.php` — Migration

Ab migration file open karo.

**File:** `database/migrations/xxxx_create_students_table.php`

`up()` function ke andar ye code likho:

```php
public function up(): void
{
    Schema::create('students', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->string('email')->unique();
        $table->string('course');
        $table->integer('fee');
        $table->timestamps();
    });
}
```

**Explanation:**

| Code                                | Explanation              |
| ----------------------------------- | ------------------------ |
| `$table->id()`                      | Student ki unique ID     |
| `$table->string('name')`            | Student ka naam          |
| `$table->string('email')->unique()` | Unique email address     |
| `$table->string('course')`          | Course ka naam           |
| `$table->integer('fee')`            | Course ki fee            |
| `$table->timestamps()`              | Created aur updated date |

Ab terminal mein command run karo:

```
php artisan migrate
```

Expected result

MySQL database mein `students` naam ki table create ho jayegi.

## **Step 3 – Model configure karo**

Ab Student Model file open karo.

**File:** `app/Models/Student.php`

Is file mein ye code likho:

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Student extends Model
{
    protected $fillable = [
        'name',
        'email',
        'course',
        'fee'
    ];
}
```

## **Step 4 – Controller banao**

Terminal mein ye command run karo:

```
php artisan make:controller StudentController
```

Ab ye file create hogi:

`app/Http/Controllers/StudentController.php`

Is file mein ye complete code likho:

```php
<?php

namespace App\Http\Controllers;

use App\Models\Student;
use Illuminate\Http\Request;

class StudentController extends Controller
{
    // Show Student Form
    public function create()
    {
        return view('students.create');
    }

    // Insert Student Data
    public function store(Request $request)
    {
        // Form Validation
        $request->validate([
            'name' => 'required',
            'email' => 'required|email|unique:students,email',
            'course' => 'required',
            'fee' => 'required|numeric|min:0'
        ]);

        // Insert Data into Database
        Student::create([
            'name' => $request->name,
            'email' => $request->email,
            'course' => $request->course,
            'fee' => $request->fee
        ]);

        // Redirect with Success Message
        return redirect()->route('students.create')
                         ->with('success', 'Student Added Successfully!');
    }

    // Display All Students
    public function index()
    {
        $students = Student::all();

        return view('students.index', compact('students'));
    }
}
```

## **Step 5 – Routes banao**

Ab `routes/web.php` file open karo.

**File:** `routes/web.php`

Ye code likho:

```php
<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\StudentController;

// Show Form
Route::get('/students/create', [StudentController::class, 'create'])
    ->name('students.create');

// Insert Data
Route::post('/students/store', [StudentController::class, 'store'])
    ->name('students.store');

// Show All Students
Route::get('/students', [StudentController::class, 'index'])
    ->name('students.index');
```

## **Step 6 – Form banao**

Ab `resources/views` folder ke andar `students` naam ka folder create karo.

Is folder ke andar `create.blade.php` naam ki file banao.

**File:** `resources/views/students/create.blade.php`

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Student Registration</title>
  </head>
  <body>
    <h1>Student Registration Form</h1>

    <!-- Success Message -->

    @endif

    @endforeach @endif
```
