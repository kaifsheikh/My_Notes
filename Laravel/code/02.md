# **Laravel Routing with Controllers (Route & Controller Method)**

## **Step 1: Controller create karein**

VS Code ka terminal open karein aur ye command run karein:

```
php artisan make:controller HomeController
```

Is command se Laravel automatically ek Controller create kar dega.

Location:

```bash
app\Http\Controllers\HomeController.php
```

## **Step 2: Controller mein function create karein**

Ab `HomeController.php` file open karein.

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class HomeController extends Controller
{
    public function index()
    {
        return "Hello World From Controller";
    }

    public function about()
    {
        return "This Is About Page";
    }

    public function contact()
    {
        return "This Is Contact Page";
    }
}

```

## **Step 3: Ab routes alag file mein create karein**

Ab ye file open karein:

```
routes/web.php
```

Ismein ye code likhein:

```php

<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\HomeController;

Route::get('/', [HomeController::class, 'index']);

Route::get('/about', [HomeController::class, 'about']);

Route::get('/contact', [HomeController::class, 'contact']);

```

## **Step 4: Browser mein check karein**

Terminal mein server run karein:

```
php artisan serve
```

# **Topic: Laravel MVC – Routing, Controller & View**:

1. **Route:** URL manage karega.
2. **Controller:** Function aur logic handle karega.
3. **View:** Website ka design (HTML) show karega.

## **Step 1 – Controller create karein**

Terminal open karein aur ye command run karein:

```
php artisan make:controller HomeController
```

Location:

```php
app\Http\Controllers\HomeController.php
```

## Ab `HomeController.php` open karein.

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class HomeController extends Controller
{
    public function home()
    {
        return view('home');
    }

    public function about()
    {
        return view('about');
    }

    public function contact()
    {
        return view('contact');
    }
}

```

## **Step 2 – Views create karein**

```bash
resources/
 └── views/
```

Is folder ke andar hum apni 3 files create karenge:

```
resources/
 └── views/
     ├── home.blade.php
     ├── about.blade.php
     └── contact.blade.php
```

**Important:** Laravel mein View files ke naam ke end mein `.blade.php` lagta hai.

### **A. `home.blade.php` page create karein**

Ismein ye HTML code likhein:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Home Page</title>
  </head>
  <body>
    <h1>Welcome to Home Page</h1>
    <p>This is my first Laravel View.</p>
  </body>
</html>
```

### **B. `about.blade.php` page create karein**

```html
<!DOCTYPE html>
<html>
  <head>
    <title>About Page</title>
  </head>
  <body>
    <h1>About Us</h1>
    <p>This is our About Page.</p>
  </body>
</html>
```

### **C. `contact.blade.php` page create karein**

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Contact Page</title>
  </head>
  <body>
    <h1>Contact Us</h1>
    <p>This is our Contact Page.</p>
  </body>
</html>
```

# **Step 3 – Routes create karein**

VS Code mein ye file open karein:

```bash
routes/web.php
```

Ismein ye code likhein:

```php
<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\HomeController;

Route::get('/home', [HomeController::class, 'home']);

Route::get('/about', [HomeController::class, 'about']);

Route::get('/contact', [HomeController::class, 'contact']);

```

# **Step 4 – Ab project run karein**

Ye command run karein:

```

```
