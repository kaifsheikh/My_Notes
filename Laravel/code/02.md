# **Laravel Routing with Controllers (Route & Controller Method)**

## **Step 1: Controller create karein**

VS Code ka terminal open karein aur ye command run karein:

```
php artisan make:controller HomeController
```

Is command se Laravel automatically ek Controller create kar dega.

Location:

```bash
app\Http\Controllers\HomeController.php
```

## **Step 2: Controller mein function create karein**

Ab `HomeController.php` file open karein.

```php

<?php

namespace App\Http\Controllers;

class HomeController extends Controller
{
    public function index()
    {
        return "Hello World From Controller";
    }

    public function about()
    {
        return "This Is About Page";
    }

    public function contact()
    {
        return "This Is Contact Page";
    }
}

```

## **Step 3: Ab routes alag file mein create karein**

Ab ye file open karein:

```
routes/web.php
```

Ismein ye code likhein:

```php

<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\HomeController;

Route::get('/', [HomeController::class, 'index']);

Route::get('/about', [HomeController::class, 'about']);

Route::get('/contact', [HomeController::class, 'contact']);

```

## **Step 4: Browser mein check karein**

Terminal mein server run karein:

```
php artisan serve
```
